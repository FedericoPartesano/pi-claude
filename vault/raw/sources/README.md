# Fonti grezze

Fonti immutabili: il modello le legge e non le modifica mai. Ogni fonte ingerita ha una pagina riassunto in `wiki/sources/`.

Le fonti principali sono già nel repository e non vengono copiate qui, per non duplicarle:

- `../../NOTES.md` — storia tecnica e decisioni del bridge
- `../../HANDOFF.md` — stato dei lavori per la ripresa
- `../../eval/vault/REPORT.md` — misure del vault (solo vettori contro ibrido)
- `../../intents/` — intent del progetto

Fonti esterne (articoli, pagine web, trascrizioni) vanno salvate in questa cartella in markdown; immagini in `raw/assets/`.
