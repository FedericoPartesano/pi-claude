# Costo fisso in token

Regola di progetto: ogni aggiunta deve costare il meno possibile su ogni richiesta. Righe di prompt corte e stabili (restano in cache), tool spenti finché non servono ([[tool-su-richiesta]]), schemi di tool registrati solo quando c'è qualcosa da usare (come in [[extension-vault]]). Riferimento: `pi` ~3,6k token per richiesta, `pi-full` ~3,8k.
